Phantom Display

Installation

Un seul clic : installe le pilote d'écran virtuel (MIT, signé), l'application, le démarrage automatique avec Windows et le raccourci du menu Démarrer.

Écrans virtuels

Un écran virtuel reste « allumé » pour Windows quand tes écrans physiques sont éteints : les benchs GPU mesurent alors la vraie charge d'affichage.

Raccourci « tout désactiver »

Aucun par défaut. Clique le champ puis appuie sur ta combinaison (au moins un modificateur). Échap pour effacer.

GPU des écrans virtuels

Carte qui rend les écrans virtuels. Choisis celle que tu benches.
